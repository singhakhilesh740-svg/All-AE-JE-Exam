Available CSS Classes (from chapter-notes.css)
  • Banner block: <div class="chapter-banner"> with .series-label, h1, .subtitle, .chapter-meta > span
  • Section: <div class="section-wrap" id="..."> wrapping <h2 class="section-title"><span class="sn">01</span> Title</h2>
  • Sub-section heading: <h3 class="sub-title"> · Mini heading: <h4 class="mini-title">
  • Inline highlights: <span class="date">, .name, .term, .fact, .place
  • Callout boxes: <div class="exam-box">, .fact-box, .mnemonic-box — each with a <div class="box-label">
  • Table: wrap with <div class="table-wrap"><table>...</table></div> · use .td-date, .td-exam in cells
  • Tag pill: <span class="tag">Label</span>
  • Divider: <hr class="divider">
⚠️ Do NOT paste: <html>, <head>, <body>, <style>, <script>, sidebar <nav>, progress bar, or print button. The viewer adds these automatically.
